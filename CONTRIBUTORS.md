# Contributors

This file tracks contributions to NexiPi for reward attribution purposes.

> **Purpose**: Aligns with the [Contributor Rewards](README.md#-contributor-rewards) model. When NexiPi achieves commercial success, contributors are compensated based on impact. This file is the source of truth for that record.

## Impact Scoring Guide

| Weight | Criteria |
|--------|----------|
| **High** | Core feature shipped, architecture decisions, security fixes, breaking changes |
| **Medium** | Refactoring, test coverage, docs, CI/CD, bug fixes |
| **Low** | Typo fixes, minor improvements, issue triage, community support |

## How to Be Listed

1. Open a PR or issue with a clear description
2. Use conventional commits (`feat:`, `fix:`, `docs:`, etc.)
3. Tag issues with relevant labels (`good first issue`, `help wanted`, `contributor-reward`)
4. Maintainers review and log contributions here quarterly

## Reward Distribution Principles

- **Transparency** — Quarterly public reports on project health and distribution
- **Proportionality** — Pool split by impact score, not raw count
- **Early contributors prioritized** — First movers shape the project's direction
- **Non-code contributions valued** — Docs, design, community, and ideas count
